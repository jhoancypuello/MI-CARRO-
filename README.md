# Honda Accord LX 2020 — PWA v5

Esta versión recupera el estilo visual más parecido al diseño inicial y mantiene las funciones de mantenimiento.

Incluye:
- Inicio con resumen del vehículo.
- Diagnóstico / Check Engine.
- Consulta de códigos genéricos OBD-II P/B/C/U.
- Base online de 9,533 códigos genéricos cuando hay Internet.
- Parser preparado para respuestas DTC OBD (por ejemplo, modo 03).
- Datos en tiempo real con PIDs comunes.
- Mantenimiento con tipo, fecha, millaje, notas, editar y eliminar.
- Historial.
- Verificación de fuente, hora y respuesta OBD.

Importante:
La PWA de Safari/iPhone no puede abrir directamente un adaptador Bluetooth genérico mediante Web Bluetooth. La lectura real del vehículo requiere una ruta de comunicación compatible con iPhone. Esta versión no inventa una conexión: muestra claramente cuándo los datos son de demostración y cuándo serán de OBD real.
